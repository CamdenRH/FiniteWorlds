# Baseline visual evidence — seed 12345

These pre-refinement maps sample the 64-block macro grid, not final Minecraft columns. River line color identifies the extracted network. Relief brightness is normalized within each diagnostic; it is not an absolute Y scale and should not be compared numerically with phase 4 colors. The dense near-parallel stream pattern and broad elevated surfaces motivated phases 1–4. Phase 4 includes physical column sampling, absolute elevation colors, labeled height profiles and views without vertical exaggeration.
